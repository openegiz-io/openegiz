# Roadmap

## v2.0.0

- Support a localhost Dev Profile, a TLS-enabled Production Profile, and a self-contained Kubernetes deployment from the same repository.
- Publish multi-architecture first-party images and an OCI Helm chart. Verify Compose on amd64 and arm64 and Helm in kind.
- Provide an [Offline Bundle](https://github.com/openegiz-io/openegiz/issues/44) to archive and restore released deployments without the original registries or Git hosting.

## After v2.0.0

Maintain dependency pins and release checks, address operator feedback from self-hosted deployments, and improve the Reference Examples where they expose gaps in the Telemetry and Twin workflows. Follow [open issues](https://github.com/openegiz-io/openegiz/issues) for scope and status.
